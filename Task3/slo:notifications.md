Сервис: notification
Назначение сервиса: Сервис отправляет уведомления покупателям и продавцам через смс, whatsApp business API и пуш уведомления. Также обеспечивает очередь, повторную отправку, дедупликацию и учет статуса доставки сообщения

SLI 
1. Notification API availability - Доля успешных ответов API отправки уведомлений - Измеряется как доя успешных запросов на долю всех запросов
2. Notification dispatch latency - Доля уведомлений, поставленных в очередь или отправленных провайдеру за порог времени - Измеряется как доля поставленных за порог времени на долю всех уведомлений. порог = 30 сек
3. Delivery success rate - Доля отправленных сообщений с подтверждённой доставкой - Измеряется как доля доставленных на долю всех событий

SLO 
1 - SLI 1. Целевое значение более 99,9%
2 - SLI 2. Целевое значние более 99% уведомлений за 30 сек
3 - SLI 3. Целевое значение более 95% СМС и более 90% WhatsApp сообщений доставлены

SLA
1. Транзакционные уведомления о заказе и платеже отправляются своевременно - Целевое значение ≥ 98% уведомлений отправлены за 30 секунд - Последствия нарушения: анализ очереди и интеграций, эскалация при системной задержке
2. Покупатель получает статус заказа - Целевое значение ≥ 95% сообщений доставлены - Последствия нарушения:  проверка провайдера, повторная отправка при технической ошибке
3. Продавец получает уведомление о новом заказе - Целевое значение ≥ 98% уведомлений отправлены за 30 секунд - Последствия нарушения: компенсационный процесс при подтверждённой потере уведомления
4. Система не отправляет дубликаты критичных уведомлений - Целевое значение ≤ 0,5% дубликатов - Последствия нарушения: исправление идемпотентности и логики переотправки
