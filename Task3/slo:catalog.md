Сервис: Catalog
Назначение сервиса: Сервис для поиска товаров, отображения каталога, отображение информации в карточке товара. Данный сервис является частью критического пути оформления и заказы товара.

SLI
1. Availability - Доля успешных ответов API каталога и поиска - Измеряется как доля успешных запросов/долю запросов. Под успешными ответами считаем http = 2xx 
2. Latency - Доля запросов поиска и карточки товара, отвечающих быстрее порога - Измеряется как количество запросов быстрее порога/доля ответов. Порог = 500мс
3. Search quality - Доля поисковых запросов, возвращающих релевантный результат - Измеряется как доля сессий, в которых пользователь инициировал хотя бы один результат поиска

SLO 
1 - SLI 1. Целевое значение >= 99,9% 
2 - SLI 2. Целевое значение >= 99% запросов быстрее 500мс
3 - SLI 3. Целевое значение >=  70% поисковых сессий с откртым результатом

SLA
1. Каталог и поиск доступны для покупателей и продавцов - Целевое значение: более 99,8% за месяц. Последствия нарушения = эскалация СТО, публичный статус, компенсация продавцам при подтвержденном простое более 60 минут
2. Поиск и карточка товара отвечают быстрее - Целевое значение: более 98% запросов быстрее 500 мс. Последствия нарушения: план оптимизации в течении 5 рабочих дней
3. Поиск возвращает полезные результаты - Целевое значение: более 65% поисковых сессий с открытым результатом. Последствия нарушения: приоритезация улучшения поиска и каталога
