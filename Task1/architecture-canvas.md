Architecture Canvas Inception

Ценностное обоснование
Система необходима для работы нового маркетплейса в Африке. Платформа выступает посредником между покупателем и продавом для совершения комерческих сделок (покупка от одежды до электроники).
Ключевые заинтереснованные стороны
	Пользователи - т.е покупатели товаров на новом маркетплейсе
	Заказчики - Africa  Delivery
	Операционные и технические участники: Инвестор, CEO, CTO, CFO, руководитель маркетинга Africa Delivery, внешний юрист 
Ключевые функции
	MVP
		Каталог товаров по категориям
		оформление заказа с оплатой через M-PESA и Flutterwave, уведомление по смс и в мессенджерах
		Личный кабинет покупателя и базовая аналитика для CEO 
	Через год
		Личный кабинет продавца с аналитикой
		Логистическая интеграция с отслеживанием отправлений
		Обработка возвратов и защита от мошенничества на пунктах выдачи заказов с обязательной видеофиксацией
		Поддержка нескольких языков		

Требования к качеству
	Mission critical - 99,9 % времени безотпказной работы
	Cloud Native (CNCF)
	Возможность размещения платформы у любого из доступных провайдеров (Amazon,Google, Microsofn или on-premise)
Деловой контекст
	Взаимодействие с платежными сервисами M-Pesa и Flutterwave
Ключевые решения
	Система должна быть Mission critical
	Хранение перс данных должно быть в рамках закона NDPR в Нигерии
	Также система должна удовлетворять закону POPIA
Составные части системы
	БД
	Сервисы
	Интеграции с платежными севрисами
	UI для продавца и покупателя
	Аналитические подсистемы
	На данном этапе трудно выделить более конкретную детализацию для текущего блока Canvas  
Технологии
	Golang
	Oracle
	интеграции с WhatsApp* Business API, Sendbox API (Нигерия) и Sendy (Кения), Flutterwave API, M-Pesa API, Paystack.
Риски и недостающая информация
	На данном этапе не определен полностью скоуп проекта. Есть разногласия между ЛПР. Ограниченный бюджет. Крайне ограниченные по времени рамки реализации проекта
